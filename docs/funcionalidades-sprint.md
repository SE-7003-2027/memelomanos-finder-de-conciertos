# Funcionalidades comprometidas para el sprint

## Descripción

El equipo se compromete por ahora a desarrollar las siguientes funcionalidades básicas para el proyecto:

- Búsqueda de conciertos por artista.
- Visualización de la información básica de un concierto, como artista, fecha, ciudad o lugar.
- Lista de conciertos disponibles.
- Creación y consulta de un perfil de usuario.
- Marcar conciertos de interés para el usuario.

## Consideraciones

Estas funcionalidades inicialmente utilizarán datos de prueba y no dependerán todavía de APIs o bases de datos externas. La integración con servicios externos podrá realizarse posteriormente conforme avance el desarrollo del proyecto.
