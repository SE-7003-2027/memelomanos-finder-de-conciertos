# Tecnologías a utilizar

Para el desarrollo de nuestro proyecto se utilizará **Java** como lenguaje de programación y **Java Swing** como biblioteca para la interfaz gráfica del programa. Nuestra elección busca darnos un entorno de desarrollo adecuado para la lògica del programa, y que al mismo tiempo, se tenga una interfaz gràfica que ayude al usuario a poder interactuar con el sistema.

## Java

**Java** será el lenguaje de programación del proyecto. Se utilizará para implementar la lógica de la aplicación,manejo de los datos y funcionalidades del programa.

Java al ser un lenguaje orientado a objetos, facilita organizar el proyecto mediante clases y objetos, así separando responsabilidades del programa y tener una estructura organizada y fácil de entender.

Nuestras razones para utilizar Java son:

* Amplia variedad de bibliotecas y herramientas para desarrollar programas.
* Permite estructurar el proyecto a traves de modulos/secciones
* Permite el manejo de excepciones, archivos, estructuras de datos y otros elementos necesarios para el desarrollo del programa.

## Java Swing

**Java Swing** será la biblioteca utilizada para crear la interfaz gráfica de la aplicación, puesto que Swing proporciona componentes gráficos que permiten construir interfaces para programas.

Mediante Swing podemos crear ventanas, botones, etiquetas, campos de texto, tablas, menús y cuadros de diálogo, entre otros componentes necesarios para que el usuario pueda interactuar con el sistema.

La interfaz gráfica se creara utilizando componentes de Swing y usará la lógica que desarrollaremos en Java.Así las acciones que realice el usuario mediante la interfaz podrán ejecutar las funciones correspondientes dentro del programa.

Entre los componentes que podrían utilizarse se encuentran:

* **JFrame:** permite crear ventanas para la aplicación
* **JButton:** permite crear botones para ejecutar acciones
* **JLabel:** permite mostrar textos o imagenes
* **JTextArea:** permite escribir textos largos
* **JDialog:** permite abrir una ventana de dialogo

## Integración de las tecnologías

Java y Java Swing se utilizarán a la par, pues Java se encargará de la lógica y funcionamiento, mientras que Swing se encargará de darnos los elementos para crear la interacción visual.**

La separación entre interfaz y lógica permite tener una estructura con orden,haciendo más fácil que las funciones puedan modificarse o escalarse sin tener que modificar toda la interfaz

## Tecnologías usadas

| Tecnología     | Uso dentro del proyecto                                                        |
| -------------- | ------------------------------------------------------------------------------ |
| **Java**       | Desarrollo de la lógica y funciones de la aplicación.        |
| **Java Swing** | Desarrollo de la interfaz gráfica para la aplicación. |
